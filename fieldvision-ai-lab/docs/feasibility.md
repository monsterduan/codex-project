# 岗位匹配与可行性分析

目标来源：[华为 AI应用工程师实习生，岗位意向 AI技术应用](https://career.huawei.com/cn/job-details?advertisementId=30861&positionIntentionId=11312&externalPostCode=JT2026031400153)。2026-11-01 查询页面显示更新于 2026-03-18。页面可访问不保证未来仍有招聘名额。

该岗位强调 AI 大模型/算法的应用开发、集成与迭代；需求分析、微调、RAG；数据分析、效果评估和问题定位；以及 Python/C++/Java 至少一门扎实的编程能力。页面列举多类技术经验，是可选能力方向，不需要三个月内同时精通所有算法与领域。

## 从已有经历到岗位证据

个人背景已有目标检测、嵌入式视觉、实验记录及无人平台相关项目经历。可复用的是问题理解和 Python/视觉工程经验，不能直接等同于大模型工程经验、真机闭环验收或模型性能成绩。

| 岗位能力 | 当前可以承接的基础 | 需要补上的证据 |
|---|---|---|
| 编程与集成 | Python 工程和训练工具经历 | 可读代码、测试、异常处理、独立修改能力 |
| 大模型应用框架 | 视觉系统需求和数据流理解 | LangGraph 状态流、模型接口、超时、可观察输出 |
| RAG / 向量检索 | 工程文档与实验知识场景 | 词法/语义基线、固定评测集、引用与拒答分析 |
| 数据分析和评估 | YOLO 训练日志、实验对照意识 | 同轮指标、数据版本、混杂检查、多种子实测 |
| 模型微调 | 训练流程的基本经验 | 数据构造与划分、LoRA 实验、与基线对照；算力不足时作为加分项 |
| 产品和业务价值 | 农业视觉场景 | 访谈或真实使用案例、失败样例、可复现操作视频 |

## 三个月的投入

规划期：2026-11-01 至 2027-02-01，约 13 周。每周 25–30 小时，合计约 325–390 小时。以下为规划估算，不是实测工时。

| 工作 | 小时预算 |
|---|---:|
| Python、Transformer 与检索基础，结合源码复写 | 55 |
| EvidenceRAG 主项目：数据、模型接入、评测与迭代 | 110 |
| RunLens：真实记录接入与实验分析 | 45 |
| EdgeGuard：真实视觉模型基准及诊断 | 35 |
| 文档、CI、演示和简历面试 | 40 |
| 故障、硬件及数据准备缓冲 | 40 |
| **合计** | **325** |

预算上限之外的时间优先增加人工评测与理解复盘。LoRA 需从主项目之外的余量安排；如果需要从零整理大量数据或采购硬件，应减掉该项，不能同时扩大三个模块。

## 判断

**可行：**形成一个主项目、两个配套模块的初级 AI 应用工程作品集；掌握一种应用框架；解释检索与效果评估；交付可运行服务和有来源的真实测试。

**有条件可行：**完成一次有意义的 LoRA 对照或目标设备部署。前提是已有合适数据、可用显存/算力，以及前六周的主项目达到验收标准。硬件型号和可用时间目前未确认，因此不是保底承诺。

**不可承诺：**从零训练基础大模型、三个月成为算法专家、交付生产级无人系统、达到未知岗位面试线、保证录用。学历、毕业时间、可连续实习时长和面试基础仍需单独核对。

最大的风险是开发工具写出代码，但自己不能解释或调试。每周必须保留不依赖助手的代码阅读、关键函数重写、失败原因说明和口述演示。这比增加仓库数量更能提升面试能力。

第 4 周和第 8 周做范围检查：基础代码讲不清就暂停加框架；检索没有固定评测就暂停微调；没有可追溯数据就停止写提升结论。

# 边缘视觉性能测量（自编教学资料）

推理性能测量应区分预处理、模型推理、后处理和端到端延迟。ONNX Runtime 的 session.run 计时不是相机采集到执行器响应的端到端延迟，也不能直接称为现场帧率。

基准测试先执行预热，再记录重复推理的原始耗时，报告 p50、p95、输入尺寸、batch、运行时版本和执行提供程序。比较 CPU 与 GPU 时，应说明数据复制和同步方式，并使用一致输入。

Jetson Orin NX 的真实帧率取决于模型、输入、精度模式、功耗模式、温度和运行时。本教学资料没有任何 Jetson 实测帧率，也没有设备验收结果。Windows CPU 的测试结果不能冒充 Jetson 或昇腾测试结果。

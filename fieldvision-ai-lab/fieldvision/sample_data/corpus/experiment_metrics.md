# 训练实验指标解释（自编教学资料）

YOLO 验证日志中的 mAP50 和 mAP50-95 是不同指标。比较实验优先保留同一 epoch 的 precision、recall、mAP50、mAP50-95，不能把每列最大值拼成一条不存在的结果。CSV 的指标值按 0 到 1 的小数解释，显示百分比时乘以 100。

训练日志的最佳验证轮次不等于独立测试集成绩，也不能证明该轮就是 best.pt 对应轮次。没有训练器完成事件、退出码或末轮证据时，不应把结果文件的修改时间当作训练完成时间。

两个实验的 mAP50-95 差值以百分点表示。例如从 0.60 到 0.63 是增加 3 个百分点，不是相对增加 3%。单次提高不能证明模块改动导致提升，至少需要固定数据划分和训练条件，记录种子并重复实验。
